## 这玩意儿解决什么问题

日报写着写着就变成了两种极端：

- 一种是「今天做了很多事，挺充实的」——mentor 看完不知道你做了啥
- 一种是三千字流水账——mentor 也不知道你做了啥

所以这里只留四列，写完自己都清楚：

| 列 | 写什么 | 潜台词 |
| --- | --- | --- |
| 内容清单 | 在推什么事 | 我手上有几个球 |
| 状态 | 未开始 / 进行中 / 已完成 / 阻塞 | 一眼看到进度 |
| 进展 | 今天推到哪一步 | 我不是在原地摸鱼 |
| 卡点 | 被什么挡住了 | **这里最值钱，mentor 就是来帮你解这个的** |
| 预期 | 下一步打算干啥 | 我知道自己明天要干什么 |

卡点那一列别空着。空着的卡点等于「我没问题」，等到 deadline 才说卡住了，那才是真的问题。

## 用起来是什么感觉

- **左边按日期归档** — 点「+ 新增日报」开一天，历史日报都在，周报直接抄
- **状态是彩色胶囊** — 点一下弹下拉，绿的已完成、橙的进行中、红的阻塞，mentor 扫一眼就知道该看哪行
- **格子直接点着改** — 没有编辑模式，没有保存按钮，输入即保存
- **列宽随手拖** — 进展写得长就把它拉宽，宽度记住，下次打开还是那样
- **导出 Excel** — 一键出 `.xlsx`，粘到周报里或者发给 mentor
- **导入 Excel / CSV** — 换电脑了？把导出的表格拖回来就恢复了

## 三十秒上手

1. 打开 [在线版](https://judy-1003.github.io/daily-report-board/)，或者把 `index.html` 下载到本地双击
2. 点「+ 新增项目」，把今天在推的事填进去
3. 状态点成对应颜色，卡点老实写
4. 下班前点「导出 Excel」发给 mentor，收工

## 一些实话

- 数据存在浏览器的 localStorage 里，**只在你自己这台机器上**，换浏览器 / 清缓存就没了 —— 所以重要的日报记得导出一份存着
- 没有后端、没有账号、没有埋点，谁也看不到你写了什么
- 导入的表格需要有这几列表头：`日期`、`内容清单`、`状态`、`进展`、`卡点`、`预期`，也就是导出文件的原样
- 全部代码就一个 `index.html`，不到 400 行，想改颜色改文案直接搜关键词改，不会有构建报错

## 想动手改

配色都在开头的 CSS 里，淡粉是 `#fdf2f5`，主色是 `#ef8fae`，换成自己喜欢的色号就行。
状态想加一档（比如「待评审」）就改 `STATUS` 数组，再补一条同名的 `.pill[data-s="待评审"]` 样式。
