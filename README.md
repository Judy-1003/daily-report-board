# daily-report-board

单文件工作日报看板，打开 `index.html` 即可用，无需安装任何依赖。

## 功能

- 左侧按日期归档日报列表，可新增 / 删除
- 每个项目一行，横向记录：内容清单、状态、进展、卡点、预期
- 状态为彩色胶囊下拉（未开始 / 进行中 / 已完成 / 阻塞），高度固定不随行高变化
- 表头可拖拽调整列宽，宽度与内容都存在 localStorage
- 导出 `.xlsx`（原生实现，不依赖第三方库）、导入 `.xlsx` / `.csv`

## 使用

```
open index.html
```

导入的表格需包含表头：日期、内容清单、状态、进展、卡点、预期。
